# OPC UA Connect 2.6.0 – 2.6.2

This release adds value tables, a select platform and push buttons, and cleans up entities after a category change.

## 2.6.0: value tables, select and buttons

- New **select** category for writable integer nodes: a value table maps raw values to texts and is edited in the panel. Unknown raw values show as unknown, with the raw value as an attribute.
- Integer sensors can optionally show the texts from a value table (enum sensor).
- New **button** category for writable Boolean nodes: a press sets the bit.
- Group headings in the panel are shown as plain headings.

## 2.6.1: remove the old entity after a category change

The entity of the previous category was kept disabled and showed up as a missing node with a repair. It is now deleted as soon as the entity of the new category is registered; node settings stay. A repair remains only while the replacement does not exist yet. Excluded nodes keep their entity disabled so they can be reactivated.

## 2.6.2: fix saving a category change

Saving a new category over an explicitly stored one could delete the new entity as a leftover and fail with a `KeyError`. The cleanup now waits until the registry move and the options update are applied.

## Updating from 2.5.0

Update the integration and restart Home Assistant. Refresh the browser if needed: the integration should display **2.6.2** and the panel **1.13.2**.

No endpoint recreation is required. Existing categories are unchanged; select, enum and button are opt-in per node.
