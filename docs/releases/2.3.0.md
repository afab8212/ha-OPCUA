# OPC UA Connect 2.3.0

This release adds configurable units and device classes, clearer array-field organization, and a more compact entity editor.

## Entity configuration

- Set the native unit of measurement for analog sensors and numbers using Home Assistant's standard units, None, or a custom unit.
- Configure device classes for sensors, numbers and switches, in addition to binary sensors.
- Preserve unit settings through the integration options and correctly retain an explicitly cleared unit.

Units label the native PLC value; they do not scale or convert it. Choose a device class and unit appropriate to the actual value.

## Array-of-struct fields

- New individually exposed scalar fields with symbolic `name[index].field` NodeIds receive names that include the array index.
- Rename selected existing array fields using a preview dialog. Custom names, entity IDs and NodeId mappings are preserved.
- Optionally group entities by array element in the panel. Grouping by category remains the default.

This organizes individually exposed scalar nodes; it does not add support for reading or writing whole OPC UA array values. Numeric NodeIds do not carry the symbolic structure needed for this feature.

## Redesigned entity editor — panel 1.8.0

- Compact sections for Identity, OPC UA node, Value and display, and Updates and availability.
- Responsive desktop columns and a mobile layout, with Save and Cancel fixed at the bottom.
- Switches for Always available and boolean inversion. Changes take effect only after Save.
- Search inside both NodeId and unit selectors, including keyboard navigation and no-results feedback.
- Expandable help, section icons and a live state badge in the header. State updates preserve the editing draft.

## Updating from 2.2.0

Update the integration and restart Home Assistant. If necessary, reload the browser and check that the panel displays **1.8.0** and the integration **2.3.0**.

No endpoint recreation or domain migration is required. Existing names and settings are retained. Renaming existing array fields and grouping by array element are optional. Subscription behavior remains unchanged and opt-in.
