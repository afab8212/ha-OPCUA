# OPC UA Connect 2.7.0

This release makes startup and subscriptions much faster on large PLCs and improves the side panel.

## Faster discovery and subscriptions

- Discovery browses the address space level by level with one Browse request per level and reads all variables' metadata in batched Reads. Results, their order and browse paths are unchanged.
- Read and Browse blocks are sent up to four at a time.
- Nodes with a deadband are subscribed in one request per deadband value instead of one request per node. A node whose filter is rejected is still subscribed without it.
- A burst of push updates (for example the initial values of hundreds of monitored items) is handled in one pass, so it no longer blocks the event loop or makes other endpoints' sessions time out.

## Side panel (1.18.0)

- Sort the table by clicking a column header (ascending, descending, original order).
- Setting badges line up in fixed slots from row to row.
- The category choice **Automatic** shows what it resolves to, for example *Automatic (switch)*.
- Edit several entities of an endpoint together: Ctrl/Cmd+click, Shift+click or the **Select** button on a phone, then **Edit together**.
- Compact desktop layout where only the table scrolls; phones keep larger touch targets.
- Confirmations float at the bottom and fade out; rows come back after a slow endpoint reload.
- Tabs left open across an update load the new panel build instead of running the old one.

## Updating from 2.6.2

Update the integration and restart Home Assistant. Refresh the browser if needed: the integration should display **2.7.0** and the panel **1.18.0**.

No configuration changes are required.
